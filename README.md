# Poonam Kamlesh Yevle | Personal Portfolio

A responsive, static portfolio website for Poonam Kamlesh Yevle, a Computer Science and Engineering student at Navrachana University.

## Preview locally

Open `index.html` in a browser, or serve the project directory with any static web server. No build step or package installation is required.

## Before publishing

- Replace the email, LinkedIn, and GitHub placeholders in `index.html` with real details.
- Update the footer social links from `#contact` to the matching profile URLs.
- Connect the contact form in `script.js` to a form service or backend. It currently validates required fields and displays a local status; it does not transmit messages.
- Publish the project folder with a static host such as GitHub Pages, Netlify, or another provider.

The site uses Google Fonts, Lucide icons, and Simple Icons from CDNs; those assets need an internet connection to load.
